    \\
    Working with Prof. Daniel Mosse, created a novel algorithm for finding optimal hyperparameters for various Machine Learning methods (e.g., XGBoost). Implemented the algorithm in Python and compared performance against other HPO algorithms in a real-world scenario of electrical substation intrusion detection systems (IDS).
